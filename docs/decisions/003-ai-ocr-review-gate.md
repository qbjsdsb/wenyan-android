# 决策 003：AI/OCR 内容审核闸门

- **Status**: Accepted
- **Date**: 2026-08-09
- **Scope**: OCR、AI 辅助整理、seed 发布和内容审计

## 决策

AI 生成结果和 OCR 抽取结果默认是草稿或证据线索，不是可直接发布的正式内容：

1. 任何进入正式 seed 的知识点、真题、答案框架、写作材料或来源信息，都必须经过人工审核。
2. 审核记录至少要能追溯来源版本、页码/题源、原始文本或证据位置、处理方式和审核状态。
3. AI 不得猜写原题、教材页码、引文、作者观点或“标准答案”；无法复现的内容必须保留为待核项或不进入正式 seed。
4. OCR 的“识别完成”与学术意义上的“来源已核验”必须分开。现有字段和历史内容不能被 PR-00 静默改写成更高可信度。
5. AI 可以作为用户侧可选教练，但其回答必须显式标注为 AI 辅助意见，不能回写为官方内容或自动改变发布 seed。

## 发布闸门

正式 seed 变更至少应通过：

- ID 唯一性和稳定性检查；
- 内容与来源关联无悬空；
- 题型、年份、科目代码和分值有可复核依据；
- OCR 广告、水印、页眉页脚和扫描噪音检查；
- 人工审核记录与版本快照；
- 重复构建/导入结果可复算。

## 当前边界

PR-00 只统一文档和基线，不新增可信度字段、不批量修订历史 seed，也不运行 OCR 或 LLM。后续内容审计应先建立草稿、审核和发布层，再修改 App 消费模型。

## 验收指向

当前 seed 统计和导入边界见 [当前系统基线](../architecture/current-system.md)。本决策不会把任何 AI/OCR 结果写入正式内容。
