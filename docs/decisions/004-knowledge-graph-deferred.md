# 决策 004：知识图谱 UI 暂缓恢复

- **Status**: Accepted
- **Date**: 2026-08-09
- **Scope**: 导航、数据库、知识点关系展示和后续产品路线

## 决策

当前不恢复全屏知识图谱 UI，也不重新引入 `:feature:graph` 或 `graph_nodes/graph_edges` 表。知识关系的当前产品路径是：

1. 以科目—章节—知识点树作为主结构；
2. 在知识点详情中用可点击的关联知识点展示局部关系；
3. 将关系路径和关系类型作为后续显式内容模型演进，而不是先恢复高成本画布；
4. 只有出现明确的复习收益证据和用户需求时，才重新评估全局图谱。

## 当前实现证据

- 顶层第 4 个入口是错题本，不是图谱。
- 当前 settings 中没有 `:feature:graph`。
- Room v10 的实体清单中没有 `graph_nodes`、`graph_edges`。
- 章节树和关联知识点仍是当前知识结构。

旧 ADR 保留在 [adr-001-graph-removal.md](../design/adr-001-graph-removal.md)，仅作为历史决策记录；其原“待实施”状态说明已过时，当前状态以本文为准。

## 重新评估条件

重新提出图谱时必须同时提供：明确用户任务、可验证的学习收益、节点/边来源可信度、移动端性能预算、无障碍方案、返回栈方案和数据迁移/回滚方案。在这些证据出现前，不以“路线图中曾写过”作为恢复理由。

## 验收指向

当前路由、模块、表清单和回归命令见 [当前系统基线](../architecture/current-system.md)。本决策不修改产品代码。
