# 决策 001：离线优先

- **Status**: Accepted
- **Date**: 2026-08-09
- **Scope**: 当前 Android 应用及后续 PR

## 决策

文研的核心复习路径必须以本地数据为默认真相源，并在没有网络时继续可用：

1. 知识点、章节、真题、论述题、卡片生成、FSRS 调度、错题本和已有学习记录由 Room 与内置 seed 支撑。
2. AI、在线更新检查和其他网络服务属于可选增强；没有网络或没有 API 配置时，不能阻断本地阅读、回忆、练习、评分和复习记录。
3. 不为 PR-00 引入账号、服务器、云端同步或远程内容依赖。
4. 任何需要网络的功能都必须有明确的加载失败、离线空态或稍后重试路径，不得把网络响应当作正式内容的唯一来源。

## 理由

这是个人备考工具，稳定的复习节奏、可预测的数据保存和零 API 成本优先于云端协作。当前系统已经将 Room、seed 导入和 FSRS 放在本地层；本决策固化边界，不改变现有行为。

## 影响

- 后续功能优先设计为“本地先完成，网络再增强”。
- 需要服务器的功能必须单独提出架构决策和成本/隐私评估。
- 离线可用不等于禁止联网；它要求核心任务在联网失败时仍可完成。

## 验收指向

当前模块、数据库、seed 和 CI 入口见 [当前系统基线](../architecture/current-system.md)。本决策本身不修改 Kotlin、Gradle、Room 或 seed。
