# 决策 002：稳定内容 ID 与用户记录保护

- **Status**: Accepted
- **Date**: 2026-08-09
- **Scope**: seed 内容、Room 导入和后续内容迁移

## 决策

1. 已发布的科目、章节、知识点、真题、写作材料及未来学习单元使用稳定、可追溯的 ID。
2. 修订内容时沿用原 ID；新增内容只能追加新 ID；不得因排序、标题改写或重新生成而重排、复用或静默删除既有 ID。
3. seed 导入必须按稳定 ID 做幂等更新，并在数据库事务中完成；任何使用替换插入策略的内容表都必须评估外键级联和用户数据风险。
4. 升级时不得用 seed 初始值覆盖已有的 FSRS、复习日志、错题、答题草稿、模板填写、设置或 AI 配置。新增内容可以创建初始学习记录，但已有记录必须按 ID 保留。
5. Room schema 版本只能递增；旧版本迁移必须可测试、可回滚到代码历史，禁止 destructive migration 作为正常升级手段。

## 当前代码约束

当前导入器已对已有 `MemoRecord` 按 `point_id` 跳过，仅为新知识点创建初始记录；知识点、章节、科目和真题 DAO 使用 `@Upsert`。这些是后续实现必须继续保持的行为，不是 PR-00 的新代码改动。

## 不变量

- 既有知识点、真题和章节 ID 在任何内容 PR 前后都相同。
- 用户记录的外键仍指向同一个内容 ID。
- 同一 seed 输入重复导入不会生成重复内容或重复初始学习记录。
- 发现 ID、外键或迁移冲突时先停止并报告证据，不能自动改号。

## 验收指向

基线数字、导入事务、DAO 策略和用户数据边界见 [当前系统基线](../architecture/current-system.md)。本决策不修改既有数据。
