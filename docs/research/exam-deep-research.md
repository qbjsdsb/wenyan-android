## 二、古代文学专项（50分）

### 2.1 2020-2025年真题汇编（古代文学部分）

#### 2020年（3题，50分）
1. 论述屈原《离骚》的艺术成就和独特风格。（20分）
2. 论述以韩愈为首的古文运动的基本内容。（15分）
3. 论述《红楼梦》的"诗体"小说性质。（15分）

#### 2021年（3题，50分）
1. 简述《左传》的文艺成就。（15分）
2. 论述柳永在词史上的贡献。（20分）
3. 谈谈孔尚任在《桃花扇》中的"借离合之情，写兴亡之感"。（15分）

#### 2022年（3题，50分）
1. 论述屈原的艺术成就的影响。（15分）
2. 论述苏轼在词史上的贡献。（20分）
3. 论述姚鼐的古文理论。（15分）

#### 2023年（3题，50分）
1. 结合作品分析北朝乐府民歌的思想内容和南朝乐府民歌的艺术特色。（15分）
2. 结合作品分析周邦彦词的艺术特色。（20分）
3. 结合作品分析《儒林外史》三个否定性人物形象，谈谈对封建科举制度和功名利禄观念的批判。（15分）

> **2023年610完整9题见下方"各科真题交叉对照表"**

#### 2024年（3题，约50分）
1. 《诗经》在中国文学史上的地位和影响。
2. 李白诗歌的艺术个性。
3. 《红楼梦》的叙事艺术。

#### 2025年（题型有调整，古代文学占比提升）
- 名词解释：意境、唐诗格律、晚清小说改良派
- 简答：概述宋词主要艺术风格及代表作家；阐释"文以载道"的文学观念及其体现
- 论述：结合具体作家作品，论述中国古代文论中的"气韵生动"说
- 文言文阅读：庖丁解牛（《庄子·养生主》）选段

### 2.4 教材使用策略

| 教材 | 使用建议 |
|---|---|
| **袁世硕《中国古代文学史》（马工程版，2024起指定）** | 官方指定教材，运用马克思主义历史唯物主义观点，分上中下三册九编。重点关注家国情怀、民族融合、自然观照等视角 |
| **游国恩《中国文学史》（2023前指定，南师本科教材）** | 虽已换教材，但南师学术传统根基在此。观点略陈旧、阶级意识强，但知识点覆盖全面。辅助资料：李杰、顾大鹏《〈中国文学史〉学习辅导与习题集》 |
| **袁行霈《中国文学史》** | 从文学本身出发，评价中肯，易读易理解。很多上岸学长推荐作为主要补充复习教材 |

### 2.5 名词解释出题类型（4大类型）

1. **解释一本书**：《尚书》《论语》《诚斋集》《乐章集》《古诗十九首》《辋川集》《修竹篇序》
2. **解释文学样式**：话本、乐府、神话、平话、变文
3. **作家并称/流派**：竹林七贤、唐宋八大家、江西诗派
4. **批评术语**："采缛于正始，力柔于建安""独抒性灵""屯田蹊径""七宝楼台"

### 2.6 复习方法

1. **框架意识**：三大段（先秦两汉魏晋南北朝/唐宋/元明清），再按朝代细分
2. **时间线与作品点连接**：头脑中既要有宏观概念，又要落实到具体作品
3. **背诵尽早开始**：11月才开始背300多页笔记会心态崩溃，需多次重复
4. **充分利用真题**：南师出题有显著重复性，真题是最高效的复习工具
5. **紧跟课本**：很多题目在课本上直接能找到答案
6. **复习4遍法**：第一遍仔细看→第二三遍反复记忆→第四遍考前查漏补缺

### 2.7 答题技巧

- 思路清晰，分条论述（①②③）
- 结合例子论证，避免空泛
- 积累名篇名句、典型情节人物素材
- 背诵时无需一字不差，抓住关键词复述即可
- 古代文学评论写作需引用文论：必读《文心雕龙》《诗品》（钟嵘）《沧浪诗话》《人间词话》

## 三、现当代文学专项（30分）

### 3.1 2020-2025年真题汇编（现当代文学部分）

#### 2020年（2题）
1. 结合两篇小说，谈谈鲁迅"立人"思想。（15分）
2. 结合具体作家，谈谈改革开放以后外国文学对中国作家的影响。（15分）

#### 2021年（2题）
1. 结合具体作家作品，谈谈周作人散文及其当代影响。（15分）
2. 关于中国新文学史（现代文学史）的起点，学术界有几种比较有影响力的看法？不同的起点划分意味着什么样的文学史观？请评述之。

#### 2022年（2题）
1. 五四时期新文学家对待传统文化的批判往往非常决绝，如鲁迅、胡适，说说你的看法。（20分）
2. 论述现当代文学史上小说中知识分子题材的演变。（15分）

#### 2023年（2题，30分）
1. 鲁迅认为冯至是最杰出的抒情诗人，结合作品分析其艺术特色。（15分）
2. 新写实派是20世纪八九十年代的重要流派，结合作品分析其特点和局限。（15分）

#### 2024年（2题）
1. 谈谈你对京派"田园牧歌"乡土小说的认识。
2. 80年代女性主义写作的三个主题特点。

### 3.2 高频考点分析

| 考点 | 考查年份 | 常考角度 |

| **鲁迅相关** | 2020、2021、2022、2023 | 立人思想、对当代作家影响、五四批判、冯至评价 |
| **知识分子题材小说** | 2022 | 从《伤逝》到《废都》的演变 |

**高频考点**：

| 考点 | 常考角度 |
|---|---|
| 周作人散文 | 人的文学、散文特色、对当代散文影响 |
| 新文学史起点 | 不同起点划分的文学史观 |
| 五四新文化运动 | 传统文化批判态度 |
| 外国文学对中国作家影响 | 改革开放后的影响 |
| 京派乡土小说 | "田园牧歌"特征 |
| 女性主义写作 | 80年代三个主题特点 |

### 3.3 丁帆《中国新文学史》教材重点

**上册·大陆文学重点章节**：
- 第一章 新文学三十年的晚清因素（王国维《红楼梦评论》、被压抑的现代性）
- 第二章 新文学潮（文学革命、五四新文化运动）
- **第三章 鲁迅与五四文学**（超重点）
- 第四章 京派与海派（林徽因、刘呐鸥、现代性比较）
- 第六章 智识阶层形象谱系（知识分子题材）
- 第七章 左翼文学（茅盾、丁玲）

### 3.4 教材使用策略

| 教材 | 说明 |
|---|---|
| **丁帆《中国新文学史》** | 官方指定教材，南师本校教师主编 |
| **钱理群《中国现代文学三十年》** | 比丁帆系统，强烈推荐补充 |
| 朱栋霖《中国现代文学史》 | 附文学大事年表 |
| 孔范今教材 | 较厚，有些内容真题从未考过 |

### 3.5 "从真题中看出不考什么"

- 南师大初试很少考**文艺争论问题**（现当代复试另当别论）
- 考的更多的是**作家、作品、流派、人物**
- 不仅要从真题中看出考什么，还要从真题中看出**不考什么**

### 3.6 专题整理建议

- **鲁迅专题**：小说、散文、杂文、立人思想、研究史、对当代作家影响
- **周作人专题**：人的文学、散文特色、闲适文化、对现当代散文影响
- **曹禺专题**：《雷雨》悲剧内涵、人物分析、戏剧史地位
- **女性作家专题**：冰心、丁玲、萧红、张爱玲、王安忆比较
- **现实主义流变专题**：传统现实主义→新写实主义→新历史小说
- **知识分子题材专题**：从《伤逝》《家》到《青春之歌》《绿化树》《废都》
- **乡土文学专题**：鲁迅《故乡》→赵树理→汪曾祺→寻根文学

## 四、文学理论专项（40分）

### 4.1 2020-2025年真题汇编（文学理论部分）

#### 2020年（2题）
1. 为什么说文学创造的主体是特殊的艺术生产者。（15分）
2. 论述文学意境的特征。（20分）

#### 2021年（2题）
1. 简要回答视角的内涵以及热奈特叙述视角的分类。（20分）
2. 简要回答文学接受的高潮阶段。（20分）

#### 2022年（2题）
1. 论述文学活动的四要素及其作用。（15分）
2. 根据具体作品，分析文学活动的时代风格和地域风格。（15分）

#### 2023年（2题，40分）
1. 结合作品说明如何理解典型环境的典型人物。（20分）
2. 结合作品分析期待视野的层次。（20分）

#### 2024年（2题）
1. 文学话语蕴藉属性。
2. 人物的"行动元"和"角色"两重属性。

#### 2025年
- 名词解释：文学典型、意境
- 简答：简述影响文学创作的主要社会因素

### 4.2 童庆炳《文学理论教程》五编框架

| 编次 | 章节 | 内容 | 重点程度 |
|---|---|---|---|
| **第一编 导论** | 第1-3章 | 文学理论的性质和形态、马克思主义文论 | ★★★ |
| **第二编 文学活动** | 第4-6章 | 文学作为活动、审美意识形态属性 | ★★★★ |
| **第三编 文学创造** | 第7-9章 | 特殊精神生产、创造过程、创造原则 | ★★★★ |
| **第四编 文学作品** | 第10-14章 | 文本层次、叙事性、抒情性、文学风格、典型与意境 | ★★★★★ |
| **第五编 文学消费与接受** | 第15-17章 | 文学消费、文学接受、文学批评 | ★★★★ |

### 4.3 高频考点（已考真题对应章节）

| 真题考点 | 对应章节 | 答案要点 |
|---|---|---|
| 文学活动四要素（2022） | 第四章 | 世界、作家、作品、读者（艾布拉姆斯四要素）及其相互关系 |
| 文学时代风格和地域风格（2022） | 第十三章 | 时代风格=特定时代审美理想；地域风格=地域文化影响 |
| 文学创造主体是特殊艺术生产者（2020） | 第七章 | 主体=特殊的艺术生产者（精神生产者、个体创造者） |
| 文学意境的特征（2020） | 第十四章 | 情景交融、虚实相生、韵味无穷 |
| 热奈特叙述视角分类（2021） | 第十一章 | 零聚焦/内聚焦/外聚焦 |
| 文学接受的高潮阶段（2021） | 第十六章 | 共鸣、净化、领悟、延留（余味） |
| 典型环境的典型人物（2023） | 第十四章 | 恩格斯提出；典型环境=时代社会背景；典型人物=共性与个性统一 |
| 期待视野的层次（2023） | 第十六章 | 期待视野=读者阅读前预备状态；层次：文体期待、意象期待、意蕴期待 |
| 文学话语蕴藉属性（2024） | 第十章 | 话语的含蓄性、多义性、不确定性 |
| "行动元"和"角色"（2024） | 第十一章 | 行动元=功能层面；角色=人物层面 |

### 4.4 命题规律

1. **目录小标题是题库**：考过以章节题目做简答题，把目录当题库背
2. **第四编最重点**：文学作品（叙事性、抒情性、风格、典型与意境）出题最多
3. **结合作品分析**：答题时需"文论信手拈来，引经据典"
4. **重点内容复现率高**

### 4.5 复习方法

- 以五编框架为纲，熟记每编每章核心概念
- 先背诵基本概念，再理解理论内涵
- 每个理论点准备2-3个作品例证
- 重点研究2020-2025年真题

### 6.2 命题规律

1. **题型结构**：话题写作/小论文（约50分）+ 作品评论/论析（约100分）
2. **现当代方向特点**：
   - 高频关注**鲁迅相关话题**（2020、2021连续考）
   - 注重**作家创作转型与文学史脉络**
   - 评论对象涵盖小说、散文、诗歌多种文体
   - 话题写作常结合文学史重大节点
3. **南师偏好**：比较青睐**诗歌评论**，近几年多考查当代诗作，特别是**第三代诗人**作品
4. **字数要求**：评论类通常不少于1200-1500字

### 6.4 写作四步法

| 步骤 | 内容 | 时间分配（以150分计） |
|---|---|---|
| 第一步：读题 | "整体—部分—整体"通读，记录灵光闪现的评点 | 10-15分钟 |
| 第二步：破题 | 选择评论主旨，不能贪大求全，选择一个有深度的切入点 | 5-10分钟 |
| 第三步：列提纲 | 确定论点→分论点→论据→结论的结构 | 5分钟 |
| 第四步：写作 | "总—分—总"结构，论点+论据+论证 | 60-70分钟 |

### 6.5 标题写法

- 使用"**大标题+副标题**"格式
- 大标题写明分析角度+理论术语（如"平实语言中的深沉意蕴"）
- 副标题表明以题干作品为例（如"——评艾青《旷野》"）
- 切忌《论XXX的小说创作》这样大而空的题目
- 学术要的是**规范**，而不是所谓"文采"

### 6.6 理论运用（3级难度）

| 难度 | 理论 | 适用场景 |
|---|---|---|
| 简单 | 悖论、象征、隐喻、对比、反讽、节奏 | 50分小题，一个理论即可 |
| 中等 | 陌生化、集体无意识、身份认同、不定点聚焦 | 70-100分，三段法中间段分析 |
| 复杂 | 格雷马斯行动元理论、聚焦理论 | 150分大题，两个理论组合最佳 |

### 6.7 字数标准

| 分值 | 建议字数 |
|---|---|
| 50分 | 800-1000字 |
| 70-80分 | 1500字 |
| 100分 | 1800字 |
| 150分 | 3000字 |

### 6.8 语言要求

- 文学评论**绝不等同于文学鉴赏**！鉴赏是感性的，评论是理性的
- 要有**学理性**，有理有据，体现逻辑性
- 观点最重要，其次是语言组织，文采不是特别重要
- 提到自己观点时用"**笔者**"，不用"我"
- 坚决避免理论和内容两张皮

### 6.9 复习三步法

1. **理论储备**（3-8月）：总结理论进行背诵，熟悉多种观照文学的角度
2. **真题练习**（9-11月）：拿历年真题精细化练习，手边放所有资料写到最好，自我评价+请人提意见
3. **模考**（12月）：严格按考试时间练习，考前至少练2篇（一篇诗歌、一篇散文）

### 6.10 批评态度

- 本着**实事求是**的态度，好就是好，不好就是不好
- 做到：**公正、宽容、合理、亲善**
- 不能因喜好不同而否定某种风格
- 不能因喜欢某作家而忽略其问题

### 6.11 古代文学方向专业写作特别要求

- 需考**古文标点翻译**（句读）
- 推荐**王力《古代汉语》**第一、二册
- 必读四大文论：《文心雕龙》《诗品》《沧浪诗话》《人间词话》
- 评论写作需引用诗论、词论语句（如钟嵘《诗品》对曹植评价"骨气奇高，词采华茂"）

## 七、复试F008现当代文学专题

### 7.1 复试形式

- **笔试**：F008现当代文学专题
- **面试**：抽题作答，无思考时间，需迅速反应
- **英语听力**：2篇短文（第一篇10道判断正误较难，第二篇10道填空较简单），普遍80-90分
- **综合成绩计算**：(初试成绩/5)×50% + 复试专业课笔试×25% + 专业面试×20% + 英语听力×5%

### 7.2 F008笔试真题精选（2005-2022年）

#### 2005年（阅读材料：茅盾《〈呼兰河传〉序》）
1. 结合文章对萧红小说《呼兰河传》的评析，谈谈茅盾现代作家作品研究的基本特点
2. 简述茅盾文学评论的写作方式
3. 针对文章内容做出自己的评价

#### 2006年
1. 简述茅盾的文学批评和作家作品评论写作的基本特点
2. 为什么说老舍是"北京市民社会的批判者和表现者"
3. 举出三个现当代文学研究的热点问题

#### 2007年
1. 分别列举五部《呐喊》《彷徨》中的小说
2. 列举五种现当代文学研究期刊和五位理论批评家
3. 试述《新青年》杂志在五四文学革命中的作用
4. 新写实小说和传统现实主义小说的区别
5. 以某位作家作品为例，谈文学研究的关键、如何选题、研究方法

#### 2008年
1. 魏连殳、梅行素、凌吉士、有工伯、余永泽是哪五位作家五部作品的人物
2. 50和80年代诗歌创作各选一部作品，分析与五四新诗的精神联系
3. "赵树理方向"的提出与赵树理小说的关系
4. 以周朴园、繁漪、周萍性格冲突为中心，分析《雷雨》悲剧内涵
5. 为什么说徐迟《歌德巴赫猜想》标志报告文学新时代

#### 2009年
1. 比较新写实主义与传统写实主义的异同
2. 比较巴金建国前后的创作风格变化
3. 茅盾文学批评的语言特征
4. 鲁迅作品中"我"的艺术形象及思想意义

#### 2010年
1. 诗歌赏析：艾青《我爱这土地》
2. 简述十七年文学的历史传统
3. 简述新时期话剧的艺术创新

#### 2011年
1. 鲁迅小说中体现自身经历和生命体验的作品
2. 郁达夫《沉沦》的得失
3. 选一种文体，按现代文学史不同阶段说明其变化
4. "十七年"文学作品塑造英雄典型的主要特征

#### 2013年
1. 鲁迅"五四时期散文小品的成功，几乎在小说戏曲诗歌之上"
2. 以《创业史》和《古船》为例，谈农村题材小说的变化
3. 《假如我是真的》和《陈毅市长》的思想艺术特征

#### 2014年
1. 谈谈对"没有晚清，何来五四"的看法
2. 赵树理小说在建国前后的变化
3. 《陈毅市长》《绝对信号》的思想内涵和艺术特色

#### 2015年
1. 鲁迅"五四时期的散文小品，成就几乎在小说戏剧诗歌之上"（60分）
2. 中国新写实主义文学与传统现实主义文学的异同（60分）
3. 举3个近期现当代文学研究热点（30分）

#### 2016年
1. 新月诗派前后期的差异以及意义
2. 曹禺《雷雨》的中心人物是谁？
3. 孙犁《荷花淀》的艺术特色和文学史地位
4. 列举干预生活的作家作品

#### 2017年
1. 鲁迅"五四时期，散文小品的成功，几乎在小说诗歌戏曲之上"
2. 简述现当代的乡土文学发展
3. 论述80年代以来的形式探索

#### 2018年
1. 谈谈王德威"没有晚清，何来五四"的观点
2. 简述《创业史》和《平凡的世界》的思想内容和文学史意义
3. 《陈毅市长》《野人》的思想和艺术特色
4. 纵观新诗发展史，谈谈艾青诗歌创作的意义

#### 2019年
1. 谈谈陈独秀《文学革命论》的主要内容及评价
2. 以废名、张爱玲、师陀、赵树理为例，谈创作和传统文学的关系
3. 1978年作为重要时间节点对当代文学的影响
4. 网络等媒介对当代文学发展的影响
