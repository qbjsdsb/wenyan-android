## Release scope

v0.9.26 = 新启动图标 v7.4（Google Play Books 风格）+ 批三（性能与整洁），共 6 个 commit。

### 1. 新启动图标 v7.4（commit `38b9ddf`）
- 用户反馈 v5「书堆+文」难看、要 Google 味 → 多轮打磨定稿「黑底白书」
- 手工矢量：白色双页书 + 中央 4px 书脊缝隙 + 每页 4 条文字线（末条短暗示段落结尾），墨黑 #1A1A1A 背景
- 纯 VectorDrawable（可无限缩放）+ cairosvg 渲染各密度 webp 兜底，资源 84KB → 9.8KB（-88%）
- adaptive icon 三层（background/foreground/monochrome）+ Splash 同步

### 2. 批三：性能与整洁

**性能（commit `ad86909`）**
- 详情页懒加载：KnowledgePointDetailScreen Column+verticalScroll → LazyColumn（全部 section 分 item 懒加载）
- RAG 检索质量：`searchByKeyword` 加 `ocr_status='VERIFIED'` 过滤（未校对知识点不进 AI 上下文）
- AI 成本控制：
  - RetryInterceptor 429/5xx 读取 `Retry-After` 头（服务商限流秒数优先，无则指数退避）
  - OkHttp `callTimeout(90s)` 兜底（含 SSE 长连接）
  - AiServiceImpl 全局 Semaphore(3) 并发限制（跨页面共享）

**整洁**
- i18n 资源化（commit `ace2e64`）：5 个 feature 模块约 74 处 Text 硬编码 → stringResource
- convention plugin 抽取（commit `13631da`）：build-logic + android-library-convention，11 个库模块共用配置（约 -130 行）

### 3. 修正（commit `ba0a53f`）
- RAG 停用词剔除回退：LIKE '%苏轼贡献%' 不匹配原文"苏轼的贡献"，剔除反而降低命中率（多关键词 OR 留待后续）
