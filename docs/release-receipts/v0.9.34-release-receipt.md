## Release scope

v0.9.34 = 全局横屏适配，共 4 个 commit。

### 1. 横屏双栏（`acb2649`）
- **知识卡片**：复习页横屏 Column→Row 双栏——左卡片区（占全部高度 + 大部分宽度，
  卡片突出、大、方便阅读）+ 右 200dp 操作面板（2×2 评分网格，按钮 ~90dp 更小、
  总高 ~120dp 不溢出矮横屏）
- **新增 `AdaptiveWindowLayout`**（core/designsystem）：BoxWithConstraints 暴露内容区
  尺寸 + `shouldUseDualPane(maxWidth>maxHeight && maxWidth>=600dp)` 纯函数——
  精确捕获"横屏手机"、不误触发平板竖屏；@Preview/单测可注入尺寸
- `RatingButtons` 加 `columns` 参数（横屏 2 / 竖屏 4）；`SiblingRatedHint` 窄版；
  FlipCard 限宽 720 防大平板过宽；CardsScreen 外层横屏解除 widthIn(600)
- **全局巡检**：4 个列表类 Screen（知识点/论述题/真题背题/错题本）顶部搜索/筛选栏
  限宽居中与列表对齐；AiAssistant InputBar 限宽（IME 独占语义不变）

### 2. 反复打磨（`9ef057c`，3 轮深度复查）
- **TodayPlanBanner compact 版**：横屏单行核心任务信息（~110dp→~44dp），
  释放 ~70dp 给复习卡片
- **右栏 verticalScroll 兜底**：矮横屏（~360dp 高）翻转后操作组（~318dp）超出
  右栏可用高度（~198dp）不溢出，次要操作可滚动访问
- **右栏滚动重置**：翻转/切卡 scrollTo(0)，评分按钮始终优先可见（与左栏对称）
- **SessionCompleteState 限宽**：横屏完成态不再全宽拉伸
- **QuizPracticeDetail 操作栏限宽**：与题干区对齐居中

### 3. 版本号提升 + 文档（`a200511` + `38d79f3`）
