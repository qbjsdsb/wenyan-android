## Release scope

v0.9.32 = AI 界面修复 + 功能完善 + 批次 D 合规，共 3 个 commit。

### 1. AI 界面 P0 修复（`bd84feb`）
- **输入框上方大面积空白**：根因 IME 双重消费——Scaffold 默认 `contentWindowInsets` 含 IME
  （ScaffoldDefaults = systemBars + ime），bottomBar 的 InputBar 又自行 `.imePadding()`。
  键盘弹出时内容区 `innerPadding.bottom = bottomBarHeight + IME`，输入框上方出现键盘高度空白。
  修复：`contentWindowInsets = WindowInsets(0,0,0,0)`，由 InputBar 独占 IME 处理
- **键盘 Enter 直接发送**（ImeAction.Send + KeyboardActions.onSend）

### 2. AI 功能完善（`bd71985`）
- **空状态学习问题建议**：4 个学习问题卡片（现代文学脉络/文以载道/红楼梦艺术成就/呐喊核心思想），
  点击直接 sendMessage 一键提问；触控目标 ≥48dp；文案资源化（ai_suggest_*）

### 3. 批次 D 合规 + i18n（`8e8c7b3` + `bd84feb`）
- **validateBaseUrl 强制 https**：拒绝 http:// 明文敞口（网络层已禁明文），明确提示改用 https；
  单测捕获并修复 `https:///` 无域名漏判；提为顶层 internal 纯函数 +8 单测
- **i18n 补全 6 处**：空状态提示/学习工具 4 标题（复用既有 text_02~05）/token 用量（format）/
  引用来源/横幅"知道了"（复用 text_27）；剩余硬编码仅 enum displayName（政策豁免）
