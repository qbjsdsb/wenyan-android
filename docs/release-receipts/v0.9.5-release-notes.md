## 📖 新功能

设置页"关于"分组新增"**关于与教程**"入口，加载 7 章深度教程，帮助用户全面理解软件定位、功能模块、底层原理与使用方法。

## 🎯 教程内容（7 章）

1. **软件定位与核心理念** — 以真题为纲 / 以知识网络为本 / 以深度背诵为用
2. **功能模块导览** — 5 个顶级 Tab：知识点 / 真题 / 卡片 / 错题本 / 设置
3. **FSRS-6 间隔重复算法** — 4 大公式（retrievability / difficulty / stability / interval）+ 4 状态调度 + 4 档评分 + ClockGuard 时间源对齐
4. **三档记忆机制** — EXACT 0.95 / FRAMEWORK 0.90 / UNDERSTAND 0.85 不同遗忘目标
5. **AI 助手与 RAG 架构** — RAG 检索增强 + 苏格拉底三阶段（ANALYZE → SUGGEST → SHOW_SAMPLE）+ 多服务商 + Prompt Injection 防护
6. **使用指南与学习路径** — 6 步入门 + 三阶段备考节奏
7. **技术信息与致谢** — 技术栈与开源依赖
