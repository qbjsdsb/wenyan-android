### 2. 整体界面审查修复 14 项（commit `769455b`，3 路并行审查 + 逐项验证）

**P1（明显缺陷）**
- AI 停止生成保留已生成部分内容（原直接丢弃；`withContext(NonCancellable)` 保证 UI + 持久化完成）
- AI 流式输出列表自动滚动到底部（原 streamingContent 更新不触发滚动）
- AI 流式时不再同时显示 loading 转圈（原双 item 重叠）
- 状态栏图标颜色跟随手动主题（原 `enableEdgeToEdge` 只跟随系统深色，手动深色+系统浅色看不见）
- 更新页「安装更新」安装已下载 APK（原重新联网下载，离线无法安装）

**P2（交互/布局）**
- 更新页 AnimatedContent 用参数 key 分发（原两帧都渲染最新状态，crossfade 失效）
- 论述题列表 retry 置 loading（flow 先 emit loading 再 emitAll）
- 知识点/论述题错误态禁用搜索框与筛选 chips（原可点击但不重载，误导）
- GroupedCardItem 标题 maxLines=2 + Ellipsis（论述题长标题撑高卡片）
- 设置页种子色暗色模式亮化（lerp 到白色，原深色图标看不清）
- 知识卡片跳过切新卡重置滚动（LaunchedEffect 加 card.id）
- 错题本 Snackbar 先 clear + withTimeout(5s)（对齐 CardsScreen v0.9.23 模式）
- 错题本下次复习日期行 weight(1f) + 单行省略（窄屏不换行错乱）
- 底栏跨 Tab 切换重置可见与滚动基线（原 A Tab 隐藏后 B Tab 仍隐藏）
