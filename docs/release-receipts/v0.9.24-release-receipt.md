## Release scope

v0.9.24 = 批一（AI 体验 4 项）+ 批二（工程质量 5 项），共 9 大块，2 个 feature commit。

### 批一：AI 体验升级（commit `b737f9f`）

1. **AI 真·流式输出**：新增 `chatResultStream(query, history)` 接口，OkHttp 原生 SSE 逐行解析（零新依赖），逐 chunk emit `AiStreamEvent.Delta/Complete`，UiState 加 `streamingContent` 逐字显示，告别"转圈等待 60 秒"
2. **停止生成**：`stopGeneration() = aiJob?.cancel()`，`job.invokeOnCompletion { call.cancel() }` 中断阻塞读取，已生成部分内容自动保留
3. **多轮对话上下文**：`ChatMessageDao.getRecentByConversation` + `ChatRepository.getRecentMessages`，最近 20 条历史注入 LLM，连续追问不再像新对话
4. **Token 用量统计**：`Complete` 携带 `ChatUsage` → `AiMessage.tokensUsed` 透传 + UI 小字
5. 保留 `chatResult` 兼容苏格拉底引导/回忆检测（5 处 `.first()` 零改动）
6. 新增 mockwebserver 流式 SSE 测试（core:ai 3 个）+ ViewModel 流式/多轮/token/停止回归测试（aiassistant 4 个）

### 批二：工程质量加固（commit `178658b`）

1. **R8 混淆**：`isMinifyEnabled=true`，release APK 约 26.7MB → 5.6MB（-79%），mapping.txt 验证混淆生效（AiServiceImpl 不保留、MainActivity 保留），防反编译
2. **数据库迁移测试**：`MigrationTest`（8→9、9→10，androidTest）+ room-testing + androidTest assets 指向 schemas
3. **Tab 返回闪烁修复**：EssayList/ApiConfig/StudyProgress 3 处 `stateIn(WhileSubscribed)` 改 `Eagerly`，离开超 5s 返回不再先闪 loading
4. **DAO 补索引**：exam_questions 补 question_type/answer_status 索引、knowledge_points 补 content_source 索引；数据库 9→10 + `MIGRATION_9_10`（幂等 `CREATE INDEX IF NOT EXISTS`）+ 10.json
5. **聊天计数一致性**：`ChatRepositoryImpl.appendMessage` 消息插入 + 会话计数合并为 `withTransaction`，避免异常时计数偏差（StudyProgress 评估后保留不改：并发风险低 + 纯 JVM 单测友好）
