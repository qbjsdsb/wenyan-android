## Release scope

v0.9.33 = 真题背题专项，共 3 个 commit。

### 1. 真题背题功能（`ecf307d`）
- **入口**：知识点页搜索框上方新增"真题背题"入口卡（`QuizPracticeEntryCard`），
  副标题明确"名词解释 · 简答专项，练'记得住'（论述题见论述题 Tab）"，与论述题板块划清边界
- **列表页**（`QuizPracticeListScreen/VM`）：题型（全部/名词解释/简答）+ 科目 + 年份三维筛选
  （内存过滤 346 条 < 5ms）；卡片展示题型标签（primaryContainer 底色区分）+ 科目 + 年份 +
  答案字数 + 题干预览；副标题实时显示"共 N 题 / X / Y 题"
- **详情页**（`QuizPracticeDetailScreen/VM`）：纯背诵模式——题干大字展示（ExamContentCleaner
  清洗题号）→ 点"显示答案"展开结构化参考答案（AnimatedVisibility）→ 标记"会了"（推进）/
  "不会"（写入错题本走 FSRS）；上一题/下一题同一筛选集内导航 + 进度"第 X / N 题"；
  筛选条件经 nav 参数（type/subject/year，默认 ALL）传递保持列表上下文
- **数据层**：`ExamQuestionDao.observeByQuestionTypes` 多题型 IN 查询（稳定 ORDER BY：
  year DESC + exam_paper_code + id，保证前后题导航顺序不漂移）；`KnowledgeRepository.
  observePracticeQuestions` 题型白名单封装，数据层排除 ESSAY 避免与论述题 Tab 重复
- **错题本联动**：标记"不会"→ `recordWrongAnswer(SOURCE_QUIZ_WRONG)`，错题本显示"真题练习"
- **导航**：`quiz_practice` / `quiz_practice_detail` 两个子路由（Push/Pop 转场）
- **i18n**：28 条新字符串（kp_quiz_*）

### 2. 工程质量（`ecf307d` 内，质量复查 4 项）
- **Snackbar withTimeout(5s) 防挂起**：对齐 CardsScreen v0.9.23 / WrongAnswerScreen v0.9.25
  修复模式（material3 1.5.0-alpha18 计时异常会永久挂起、状态清不掉）
- **"不会"失败提示不覆盖**：写入错题本失败且最后一题时保留失败文案（原会覆盖为成功提示）
- **详情页重试可用**：`retry()` 取消旧加载 job + 重新加载；`CancellationException` 正确
  rethrow 防止取消误入错误态（catch 直接写 StateFlow 非 emit 模式的必要防护）
- **文案资源化**：`（本题暂无参考答案）` → `kp_quiz_no_answer`
