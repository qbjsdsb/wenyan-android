## Release scope

v0.9.43 = 关联知识点导航修复 + 测试补充（合并 PR #10 `fix/related-knowledge-navigation`）。

### 修复

- **关联知识点跳转不入栈**：详情页 A → 关联知识点 B 时，`launchSingleTop` 把 `knowledge_detail/{pointId}` 动态路由的不同 pointId 折叠成同一目的地，B 不入栈、用户仍停留 A。修复：仅从非详情页进入详情时启用 singleTop，详情→详情必须正常压栈（A→B 后返回仍回到 A）
- **同知识点防重复栈项**：`shouldSkipKnowledgeDetailNavigation` 纯策略——空白 ID 或当前详情页重复点击同一 pointId 直接跳过
- **路由健壮性**：显式声明详情路由参数（navArgument）+ `Uri.encode` 路径编码，降低异常 ID 导致路由解析失败的风险

### 工程质量

- 新增 `KnowledgeDetailNavigationPolicyTest`（导航策略 4 测试）+ `GroupedCardTest`（GroupedCard UI 测试）
- 清理过时注释基线（硬编码"134 题 / 910 知识点" → 当前数据量表述）
