## Release scope

v0.9.37 = 布局与性能深度优化（4 路并行审计 + 逐条实测复核），共 1 个 commit。

### P0 级（真实性能/无障碍问题）
- **种子加载版本检查前置**（`SeedDataLoader.ensureSeedDataLoaded`）：老用户冷启动不再全量解析 5.3MB seed JSON——已初始化时只轻量解析 metadata 壳（`SeedVersionShell`）比对版本，命中直接跳过
- **卡片页拆卡缓存**（`CardRepositoryImpl`）：评分触发 memo_records 变化不再导致全量重拆数千张卡——(id, updatedAt) 排序缓存键，内容未变直接复用；缓存键顺序无关（防御排序波动）
- **今日队列共享热流**（`ReviewRepository`）：`stateIn`（ApplicationScope + WhileSubscribed 5s）消除横幅计数与拆卡的重复订阅
- **完成态语义合并修复**（`SessionCompleteState`）：仅统计信息区 merge，3 个按钮（再复习/撤销/返回）恢复 TalkBack 独立操作

### P1 级
- **shrinkResources 开启 + OkHttp keep 规则收窄**：APK 6,150,213→5,405,360 字节（**-12.1%**）
- **列表 lean 投影 DAO**（`KnowledgePointListItem`）：列表流只查展示列，不再加载 full_content/study_text 大文本
- **论述题详情 LazyColumn**：11 区块懒加载（原 Column+verticalScroll 一次性布局）
- **Retrofit 按 baseUrl 缓存**（`AiServiceImpl`）：高频问答不再重复构建 Retrofit
- **聊天历史保留上限**（`ChatRepositoryImpl`）：单会话 200 条，超限删最旧（rowid 稳定排序）+ 同步 message_count
- **卡片首帧移出主线程**：id 生成移入 Default（`sessionCardDispatcher` 可注入）

### P2 级
设置页水平边距 / 停止生成无障碍文案（`ai_stop_generating`）/ `@Immutable` 补齐（CardsUiState/KnowledgePointItem）/ `_leechWarnings.update{}` / AI 兜底错误友好化（`friendlyErrorMessage`）/ proguard 注释修正
