## Release scope

v0.9.22 = 深度审查改进批 A + 批 B，共 8 项修复。基于全仓库 3 路并行代码审查（core/database+data+fsrs / feature 模块 / 构建 CI）发现的问题，按用户要求"反复打磨不要出问题"逐项修复并验证。

### 批 A — P1 用户可感知缺陷

1. **底栏 double inset 修复**（`core/designsystem/.../WenyanAdaptiveNavigation.kt`）
   - 外层 Box 底部 padding 从 `80dp + 手势区` 改为 `80dp`，手势区交由内层 ExpressiveScaffold 消费（与顶部 statusBars 处理对称）
   - 消除用户反馈"底栏上方大面积空白"的残留根因（v0.9.21 只修了顶部，底部同类问题残留）
2. **主题保存错误提示**（`feature/settings/SettingsScreen.kt`）
   - 消费 `ThemeViewModel.errorEvents` 弹 Snackbar（此前零订阅者，DataStore IOException 时错误被静默丢弃）
3. **版本号提升**：versionCode 46→47，versionName "0.9.21"→"0.9.22"

### 批 B — P2 数据正确性加固

4. **FSRS `nextRecallStability` 除零防御**（`core/fsrs/FsrsWrapper.kt`）
   - 老数据（v1 时代 stability 默认 0）可能出现 LEARNING/REVIEW + stability=0，`s.pow(-0.1752)` = Infinity → `0*Infinity` = NaN 污染调度
   - 加 `s <= 0f` 防御退化到初始稳定性；新增复现测试先红后绿
5. **迁移补复合索引**（`core/database`）
   - `MIGRATION_7_8` 补建 `index_wrong_answers_point_id_source` / `index_wrong_answers_exam_question_id_source`（Entity 声明但迁移遗漏）
   - 新增 `MIGRATION_8_9`（数据库版本 8→9）为存量 v8 用户补索引，9.json 同步
   - SQLite 实测：迁移后 6 索引与 schema 完全一致 + 幂等
6. **recordWrongAnswer 并发修复**：查找+递增/插入合并为单个 DAO `@Transaction`（杜绝并发重复插入窗口）
7. **时间源对齐**：recordWrongAnswer/markResolved 改用 `ClockGuard.effectiveNowMillis()`（与 FSRS 调度对齐，原用 `System.currentTimeMillis()`）
8. **评分防重入**：`WrongAnswerViewModel` 加 `isRating` 锁（DUE 模式连点评分防 FSRS 重复调度）
