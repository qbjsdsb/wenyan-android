## Bug fix details

### EssayDetailScreen subtitle score=0 显示"0分"

- **原代码**（EssayDetailScreen.kt:112）：
  ```kotlin
  subtitle = uiState.essay?.let { e -> "${e.year}年 · ${e.score}分" },
  ```
- **问题**：部分论述题 score 字段为 0（OCR 未提取到分值），subtitle 显示"0分"误导用户
- **修复后**：
  ```kotlin
  subtitle = uiState.essay?.let { e ->
      if (e.score > 0) "${e.year}年 · ${e.score}分" else "${e.year}年"
  },
  ```
- **影响范围**：仅 UI 显示，无数据层/逻辑层改动
