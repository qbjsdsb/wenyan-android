## Release scope

v0.9.36 = 知识卡片全屏沉浸模式（项目首个沉浸式先例），共 2 个 commit。

### 1. 全屏沉浸模式（`1b3c621`）

- **`ImmersiveSystemBars`**（core/designsystem 新增）：`WindowCompat.getInsetsController` +
  `BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE` 隐藏状态栏 + 导航栏，滑动边缘临时唤出后自动
  隐藏；`DisposableEffect onDispose` 离开组合自动恢复系统栏（从全屏页导航到详情/AI 再
  返回，系统栏正确复隐）
- **`CardsFullscreenScreen`**（feature/cards 新增）：无顶栏 + `contentWindowInsets =
  WindowInsets(0,0,0,0)` Scaffold 内容占满全屏；左上角半透明圆形浮动退出按钮（CircleShape
  + surface 85% 透明度），全屏无系统栏返回，出口明确
- **共享复习会话**：导航层 `hiltViewModel(navController.getBackStackEntry(ROUTE_CARDS))`
  传入卡片页同一 ViewModel（@Composable provider 延迟到 composable 内容内求值，
  NavHost builder 非 composable 上下文）——当前卡片/翻转状态/会话统计实时同步，
  退出全屏无缝回到卡片页
- **横屏双栏变体**：卡片放宽 560dp（全屏高度更大，比例 ~1.45:1 仍协调）+ 右操作栏
  280dp 单列竖排评分按钮（`RatingButtons columns=1`，用户"一个个竖着排列"偏好）；
  撤销/跳过同样单列全栏宽
- **竖屏放宽上限**：无顶栏/横幅释放空间后卡片最大宽度放宽（compact→comfortable）
- **顶栏全屏入口**：卡片页有卡可复习时显示全屏按钮（加载/错误/空/完成态自动隐藏，
  避免进入无意义的全屏）；新增 `card_fullscreen` / `card_fullscreen_exit` 文案
- **全功能镜像**：Leech 警告 AlertDialog（问 AI / 查看知识点）/ 加入错题本 / Snackbar
  / 撤销跳过，与卡片页行为一致；五态 Crossfade（加载/错误/完成/空/正常复习）
- **`CardsFullscreenLayoutTest`**：w1000dp 横屏 4 断言——卡片 560dp 居中（左缘 72dp）/
  右操作栏 280dp（左缘 720dp）/ 4 档评分单列竖排左缘对齐 + 上下顺序 / 面板垂直居中
  （首按钮 top=25 非悬顶）
