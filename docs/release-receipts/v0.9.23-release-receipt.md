## Release scope

v0.9.23 = 论述题体验优化 + Snackbar 修复 + AI 功能审计修复 + 更新日志机制落地，共 4 大块。

### 1. 论述题删除年份（用户需求）
- 列表卡片、详情页、年份筛选、知识点详情"相关论述题"区块全部移除年份显示
- 筛选栏只保留科目 + 审题思路；数据层 `year` 字段保留（仅 UI 不显示）

### 2. Snackbar 常驻修复（用户反馈）
- 修复"加入错题本"通知一直不消失：先 clear 状态再显示 + `withTimeout(5s)` 兜底，保证最多显示 5 秒

### 3. AI 功能审计修复（深度审计 + 最优方案修复）
- **P1-1**：预设服务商 URL 拼接 bug（通义/智谱/月之暗面开箱即用必 404）→ 接口路径 `chat/completions` + baseUrl 版本前缀统一
- **P0-1/P0-2**：AI 助手竞态（发送中清空/新建丢消息、init 恢复覆盖）→ 统一 `launchAiTask` 管理 Job + 取消在途任务 + 安全空判断
- **P1-3**：AI 并发控制（回复中重复触发学习工具）→ 防重入
- **P2-1**：RAG 检索失败不再阻断主流程 → 降级为无上下文调用
- **P2-6**：提示词注入链封堵 → 阶段 2/3 上一阶段输出加 `<AI_CONTEXT>` 边界 + 注入警告
- 新增 5 个回归测试（防重入/清空取消/新建取消/init 恢复不覆盖/RAG 降级）

### 4. 更新日志机制（用户反馈"更新日志不变"）
- **根因**：release.yml 的 release body 是静态硬编码功能特性列表，不随版本变化
- **修复**：新增 `CHANGELOG.md` 按版本维护日志（含 v0.9.9~v0.9.22 历史 + v0.9.23），release.yml 动态读取当前 tag 版本日志作为 Release 正文"更新内容"，App 内"检查更新"界面日志随版本变化
- AGENTS.md 发布流程补充"写 CHANGELOG + 提升版本号"步骤
