### 1. 数据一致性修复（B1/B2/B3）

| # | 问题 | 影响 | 修复 |
|---|------|------|------|
| B1 | sibling 去重 FSRS 调度漏洞：原实现先 `ratedPointIds.add(pointId)` 再判断 templateType 有效性，若 cardTypeStr 无效（数据损坏/枚举变更），pointId 已加入 ratedPointIds 但 FSRS 调度被跳过，后续同 pointId 卡 shouldSchedule=false，FSRS 数据永久缺失 | 高：FSRS 调度数据永久缺失，间隔重复失效 | templateType 解析提前，仅当可调度时才 add：`shouldSchedule = pointId !in ratedPointIds && templateType != null` |
| B2 | Leech 误报（RELEARNING 状态）：原实现 AGAIN 总是 `failCount - 1` 反推 oldFailCount，但 FSRS-6 中仅 REVIEW+AGAIN 增加 lapses，RELEARNING+AGAIN 不增加。若 RELEARNING+AGAIN 时 failCount=8（未变），反推 oldFailCount=7，误满足 `7<8 && 8>=8` → 弹 Leech 警告 | 中：用户在 RELEARNING 状态答 AGAIN 时收到错误的 Leech 警告 | 根据 `updated.state` 区分：REVIEW+AGAIN → `failCount-1`，其他状态+AGAIN → `failCount`（不减 1） |
| B3 | 无 pointId 卡评分不记录学习进度：`recordStudySession` 需要 pointId 作为 last_point_id，空字符串语义错误。原实现静默跳过，无日志 | 低：数据完整性问题（当前 CardRepository 总是设置 pointId，无 pointId 卡是数据异常） | 加 Timber 警告日志 `Card with blank pointId rated, skip study progress record`，便于生产排查 |

### 2. 体验优化（M2/M4/M5/M9/M11）

| # | 问题 | 修复 |
|---|------|------|
| M2 | sibling 卡连续排列：同一知识点的 5-6 张卡（名词解释拆卡 + 论述要点 + 区分卡）连续显示，用户疲劳 + FSRS 调度被稀释 | `interleaveSiblingCards` round-robin 打散，同 pointId 卡分散到队列不同位置（类似 Anki 混合复习） |
| M4 | 翻转时背面继承正面滚动位置：用户在正面滚到底部后翻转，背面也滚到底部（但背面内容不同，应从顶部开始） | `LaunchedEffect(isFlipped) { scrollState.scrollTo(0) }` 翻转时重置滚动 |
| M5 | 完成态无法撤销最后一张：用户评完最后一张才发现评错了（如本想评 GOOD 却点了 AGAIN），Crossfade 已切到完成态，原实现无法撤销 | 完成态新增"撤销最后一张" FilledTonalButton，undo 后 currentIndex 回退，Crossfade 切回复习态 |
| M9 | 无效 cardTypeStr 静默失败：原实现 `catch (e: IllegalArgumentException) { null }` 无日志，生产环境无法排查为何某些卡未触发调度 | 加 Timber 警告日志 `Invalid cardType for pointId=...` |
| M11 | 快速切卡时旧预览闪烁：collectLatest 进入时不清空预览，新卡预览加载期间 UI 短暂显示旧卡的"6天/12天"预览（误导用户） | collectLatest 进入时立即 `_currentPreviews.value = emptyMap()` |

### 3. UI 工程化（M10）

CardsScreen 顶层使用 `hiltViewModel()` 注入，无法直接 `@Preview`。现对 Crossfade 内三种关键状态分支的私有组件添加 `@Preview`：

| Preview | 组件 | 展示内容 |
|---------|------|----------|
| CardsNormalReviewPreview | CardReviewContent | 进度条 + 翻转卡（背面答案）+ 四档评分按钮 + 撤销/跳过 |
| CardsEmptyPreview | EmptyState | CheckCircle + "今天没有到期卡片" + 描述文案 |
| CardsFinishedPreview | SessionCompleteState | AutoAwesome + 统计卡（12/3/75%）+ 鼓励文案 + 三个按钮 |
