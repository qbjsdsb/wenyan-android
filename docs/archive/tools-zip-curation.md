# `tools.zip` 历史资料归档说明

状态：`ARCHIVED`。本次只归档可追溯的来源元数据和质量审计结果，不把历史压缩包变成 App 的内容源。

## 归档结论

原包大小约 204.5 MB，包含 368 个条目，解压后约 404 MB。清单记录 208 份资料，其中 172 份已处理、36 份跳过；主要内容包括历史来源索引、教材处理统计、真题拆分结果、候选知识点和旧管线脚本。

本次纳入仓库的只有 `tools/legacy/` 下的脱敏元数据：

| 文件 | 用途 | 是否含正文 |
|---|---|---:|
| `source-manifest.json` | 来源、类别、文件类型、处理状态和哈希追溯 | 否 |
| `textbook-structure-summary.json` | 教材页数、字符数、OCR 评分、章节切分质量 | 否 |
| `exam-question-audit.json` | 历史真题候选的结构统计和质量债务 | 否 |
| `knowledge-candidate-audit.json` | 候选知识点覆盖、冲突 ID、关系数量 | 否 |
| `curate_tools_zip.py` | 可重复生成上述筛选结果 | 否 |

## 重要质量边界

- 历史真题候选共 481 条，全部来自 OCR 处理结果；其中 460 条解析文本检测到联系方式、店铺广告或扫描水印，21 条缺少解析文本，全部缺少分值字段。因此它们不能直接覆盖正式题库。
- 候选知识点共 909 条，旧结果标记为单一来源“其他”，没有多来源知识点，并有 43 个冲突 ID；冲突项只能作为待审清单。
- 教材结构统计可帮助检查覆盖和切分粒度，但不证明 OCR 正文已经人工逐页核验。
- 旧流程中的 `ocr_status=VERIFIED` 是管线状态，不等于事实正确或版权授权。

## 未纳入内容

原始教材/PDF、完整 OCR 文本、完整真题题干和答案、完整 TOC 文本、安装包、SDK/JDK/Gradle、缓存、日志、字节码、测试产物和 Windows 绝对路径均未纳入。正式 seed、已有内容 ID、Room 数据和用户学习记录也未因本次归档改变。
