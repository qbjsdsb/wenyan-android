# 文研App 四科考研内容审计报告（南师大对标）

> 日期：2026-08-03
> 目标：对照南师大中国现当代文学考研（610 文学基础 + 806 专业写作）官方范围，审计 App 四科知识点是否足够
> 方法：① 南师大官方参考书/科目调查（丁帆《中国新文学史》、聂珍钊《外国文学史》、童庆炳《文学理论教程》等）② 历年真题考点对照 ③ 教材结构（分期/文体/作家）系统检查

## 一、南师大考试结构（调查确认）

- **初试专业课**：610 文学基础（综合 150 分，含文学理论 + 中国古代 + 现当代 + 外国）+ 806 中国现当代文学专业写作（或 801，含作品论析/话题写作）
- **官方参考书**（2026）：
  - 文学理论：《文学理论教程》(童庆炳) / 《文学理论导引》(周宪)
  - 古代：《中国文学史》(游国恩) / 马工程版（袁世硕）
  - 现当代：《中国新文学史》(丁帆，上下册，**1912 起点，含台港澳**)
  - 外国：《外国文学史》(聂珍钊，**欧美部分古代至20世纪**)

## 四、结论

1. **四科主体内容：够用** —— 古代/理论最完整，外国基本完整，现当代主流考点覆盖大半
2. **但现当代存在 10+ 个真实缺口**，其中 **5 个是南师大真题考过的**（杨朔模式/重写文学史/探索戏剧/解放区文学/希腊希伯来精神），不补有备考盲区
3. **教材框架偏差**：App 用钱理群《三十年》（1917 起点、无台港澳），南师大官方丁帆《中国新文学史》（1912 起点、含台港澳）——建议按丁帆框架补台港澳板块
