## 三、数据格式规范（对齐现有 935 知识点）

```json
{
  "id": "kp_00936",               // 935 + 递增
  "title": "史铁生",              // 简洁名词短语

  "core_conclusion": "史铁生（1951-2010）……",              // 核心结论（答题要点）
  "study_text": "……",             // 学习文本（比 core 更详）
  "full_content": "……",           // 全文（study_text 基础扩展）
  "subject": "中国现当代文学",
  "tags": ["史铁生", "当代文学", "生命哲思"],
  "difficulty": 2,
  "conflict_flag": false,
  "entities": [{"name": "史铁生", "type": "PERSON"}],
  "relations": [],
  "source_count": 1,
  "textbook_sources": [{"source": "丁帆《中国新文学史》", "page": 0}],
  "merged_at": "2026-08-03T00:00:00.000000",
  "exam_frequency": "HIGH"
}
```

**要求**：
- id 从 kp_00936 递增，不覆盖现有
- 内容严格依据教材/真题，杜绝臆造；作品原文出处标注
- 考频按真题出现频率 + 教材地位综合判定
- tags/entities 格式与现有一致（entities 简单人物/作品标注）

## 四、实施步骤

1. **数据准备**：Python 脚本生成 25 个知识点 JSON（对照清单逐一撰写内容）
2. **更新 seed_data.json**：追加知识点 + 更新 metadata.version（2.16.0 → 2.17.0）与 description
3. **数据校验**：
   - 数量校验：935 → 960
   - 格式校验：字段完整、id 唯一、subject 合法
   - 内容校验：无 OCR 乱码、无重复知识点、textbook_sources 合理
4. **构建验证**：assembleDebug + 单测（seed 加载测试确认 960 知识点正确导入）
5. **提交推送**（独立 commit）
