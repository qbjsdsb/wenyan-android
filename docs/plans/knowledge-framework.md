# 知识点框架浏览方案

## 目标

知识点首页默认展示“框架”，用户按“科目 → 时期/阶段 → 专题 → 知识点”逐层进入；原有的搜索、科目筛选和知识点平铺列表保留为“列表”模式。

本阶段先整理中国现当代文学的 181 个知识点，其他三科继续使用旧的文学史时段规则，后续按同样标准逐科迁移。

## 框架原则

- 章节 ID 是稳定的业务标识，标题调整不能改变 ID。
- 每个种子知识点只有一个主要归属；跨专题关系通过 `relatedIds`、标签和详情页关联知识点表达，不在树中重复复制。
- 章节归属使用显式配置，不把标题关键词匹配当作最终分类依据。
- 导入前校验节点 ID、父节点、循环、失效知识点和未归类知识点；校验失败时事务不会开始。
- 种子升级只 Upsert 章节和知识点，保留已有 MemoRecord、FSRS 调度、复习记录和来源记录。

## 资料依据与边界

目录同时参考现代文学按“文学革命—三十年代—抗战与解放区”的教学脉络、当代文学按“十七年—文革—新时期—九十年代以来”的常见分期，并保留台港文学作为独立入口。具体知识点仍以项目已导入的教材来源、真题关联和现有内容为准；分期存在学者差异的边界点，不在框架层伪装成唯一学术答案。

## 验收标准

- 181/181 个现当代知识点均有有效归属，且不存在重复归属。
- 框架节点 ID 唯一、父级有效、无循环、标题非空。
- 从旧版本升级后，已有 MemoRecord 和 FSRS 字段数量及内容不变。
- 框架模式、列表模式、搜索和知识点详情跳转均可用。
- 空数据、数据库异常、系统返回键、横屏、深色模式和 TalkBack 不引入回归。
