v3 设计说明

构图：圆角矩形印章（圆角 12dp，M3E medium-large shape）+ "文"字 4 笔画

笔画结构（标准"文"字）：

  • 点（顶部圆点，r=2.5dp，圆心 54,35）— v2 缺失，v3 补全
  • 横（矩形 28×4dp，y=42-46）— 居中
  • 撇（梯形，从横画上方交叉点向左下，上宽 4dp 下宽 2dp 出锋）
  • 捺（梯形，从横画上方交叉点向右下，上宽 4dp 下宽 3.5dp 顿笔）

颜色：墨黑 #2C2C2C + 米色 #F5F1E8（与 App 主题一致）

谷歌味道：类比 Google Docs 的"卡片 + 字母"构图，单一焦点 + 简洁几何

精致：圆角 12dp（M3E shape）+ 笔画粗细变化（撇出锋 2dp / 捺顿笔 3.5dp）

克制：2 元素 + 2 色，无渐变无阴影

规范：Adaptive Icon safe zone（72x72）内 6dp 边距 + monochrome 层（Android 13+）
